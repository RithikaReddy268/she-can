# She Can Foundation Website

A simple and responsive website created for the She Can Foundation internship task.

## Features

- Home Page
- About Section
- Women Empowerment Image
- Join Us Page
- Responsive Design
- Footer on all pages

## Pages

### index.html
- About She Can Foundation
- Image Section
- Join Us Button
- Footer

### home.html
- Home Page
- Mission and Vision
- Education, Skill Development, and Community Support Cards
- Footer

### joinus.html
- Thank You Page for Volunteers
- Return to Home Button
- Footer

## Technologies Used

- HTML5
- CSS3

## Project Structure

```text
she-can/
│
├── index.html
├── home.html
├── joinus.html
├── style.css
└── README.md
```

## Purpose

The She Can Foundation website aims to spread awareness about women empowerment and encourage people to support the foundation's mission.
